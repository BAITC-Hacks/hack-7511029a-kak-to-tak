# Умный подбор подрядчиков — Kak to tak

Прототип для HackAlem AI, трек #79-lite. Помогаем выбрать до трёх
event-подрядчиков из предоставленного каталога и объяснить выбор.

## Первый этап

Реализованы загрузка 66 профилей, обязательные фильтры, проверка календаря,
различение отсутствующей категории и неподходящих кандидатов. Списки внутри CSV
разделены `|`; пустая длительность означает неприменимость ограничения.
Исходные признаки synthetic, city_imputed, price_imputed сохранены.

Порядок пока базовый: начальная цена, затем ID. Это не окончательное смысловое
ранжирование. Текущие объяснения шаблонные; AI, индивидуальные объяснения и веб-интерфейс
будут добавлены на следующих этапах. Бронирование в задачу не входит.

## Запуск

Нужен Go 1.22 или новее. Выполнять из корня репозитория:

```sh
go run . -city Алматы -category Ведущий -date 2026-10-15 -format корпоратив -budget 1000000
go test ./...
```

Ответ — JSON. Необязательные параметры: `-language русский`, `-hours 6`.
Календарь известен только для 23.09.2026–31.12.2026; другие даты отклоняются.
Цена «от» не гарантирует итоговую стоимость. Причины исключения могут пересекаться.

## Данные

`data/contractors.csv` — исходный CSV организаторов без изменений, 66 профилей.
Имена анонимизированы, 13 профилей помечены синтетическими организаторами.
Добавленных командой профилей пока нет. Часть цен и городов заполнена при
подготовке датасета; соответствующие признаки сохраняются в ответе.

## Следующие этапы

1. Смысловое соответствие пожеланиям, объяснения с опорой на факты профиля.
2. Веб-форма и карточки, понятные причины отсутствия результатов.
3. Демосценарии: плотная и редкая категории, пустая выдача, смена даты.
4. Проверка полного сценария, документация запуска и подготовка защиты.
